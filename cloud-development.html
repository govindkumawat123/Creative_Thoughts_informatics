CHOOSE THE RIGHT
APPROACH FOR YOUR
EXISTING APPLICATIONS

Not every application needs to be rebuilt to move to the cloud. The right approach depends on the current architecture, business priorities, technical limitations, cost, and future requirements.

Rehost

Move an application to the cloud with minimal changes when the existing application can continue to serve its purpose.

Replatform

Move an application to a more suitable cloud platform with selected changes to improve operations or management.

Refactor

Improve the application's code or architecture while retaining its core functionality.

Rearchitect

Redesign the application architecture when the existing design limits scalability, performance, reliability, or future development.

The appropriate strategy should be selected after assessing the application and its dependencies. Modernization is not always necessary for every workload.
